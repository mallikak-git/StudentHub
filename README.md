# 📚 StudentHub

StudentHub is a modern Flutter application that helps students organize their academic life in one place.

## Features

- 📅 Event Management
- ✅ Task Manager
- ⏰ Study Timer (Pomodoro)
- 💰 Budget Manager
- Clean and Modern UI

---

## Built With

- Flutter
- Dart
- Material Design
